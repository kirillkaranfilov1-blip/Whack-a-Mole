# Whack-a-Mole

## О проекте

**Whack-a-Mole** — простая браузерная игра «Ударь крота», созданная с использованием HTML, CSS и JavaScript.

Игрок должен нажимать на появляющегося крота и набрать как можно больше очков за ограниченное время.

## Технологии

- HTML5
- CSS3
- JavaScript
- DOM
- LocalStorage

## Возможности

- Система подсчёта очков
- Таймер игры
- Сохранение лучшего результата в LocalStorage
- Случайное появление крота
- Постепенное ускорение игры
- Кнопка запуска и повторного запуска игры
- Сообщения о результате игры

## Как играть

1. Нажмите кнопку **«Начать игру»**.
2. Следите за игровым полем.
3. Нажимайте на крота, когда он появляется.
4. За каждое попадание начисляется 1 очко.
5. Кроты появляются всё быстрее.
6. После окончания времени игра покажет результат и рекорд.
